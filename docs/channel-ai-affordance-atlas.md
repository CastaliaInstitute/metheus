# AI interaction patterns for the 36 channels

**Draft design atlas · 0.1 · not Human Design doctrine**

This atlas explores one practical question: when a person explicitly supplies a chart in which both endpoints of a topology-defined channel are active, what AI interaction could combine the two gate-level activities in a useful way?

The rows below are design proposals composed from the matching entries in the [64-gate AI affordance catalog](../catalog/gate-ai-affordances.json) and the versioned [BodyGraph topology](../catalog/human-design-bodygraph-topology.json). A channel row is a *two-part interaction format*, not an interpretation of a person's capacity, a channel mechanism, a prediction, or a biological function. The endpoint names are source-attributed symbolic labels. The plain-language activity should remain useful if the person hides or rejects the symbolic lens.

## Interaction rule

1. Answer the person's stated request first. Use the supplied active gates only to select an optional interaction format.
2. When both endpoints are active, combine their catalog activities only if the combination helps the stated goal. Use the sequence in the table as a starting point, not a mandatory script.
3. When one endpoint is active, do not call the channel defined. Offer the other gate's activity only as an optional complement when it is clearly useful.
4. When neither endpoint is active, do not infer or recommend a channel-based activity from the chart. The user can still choose any activity in the catalog without chart context.
5. Keep the symbolic label secondary. Do not say that the AI activates, completes, supplies, or defines a channel. Record use and the person's later report separately; neither proves the symbolic model.

## How to evaluate a pattern

Treat each row as a prototype interaction, not a recommendation. A useful evaluation asks whether the person found the format relevant, clear, accessible, and easy to stop or change. Compare it with the same activity offered without chart framing; otherwise a favorable reaction cannot tell us whether the activity, the symbolic framing, or something else mattered. Do not infer hormone changes, psychological traits, relationship quality, or channel effects from engagement or self-report.

For the current Matrix prototype, channel pairings are derived from the supplied gate list and topology. The model receives gate-level activity entries plus the set of complete channels; it is instructed to combine endpoint activities only when they fit the request. This atlas does not add new runtime channel semantics or change selection behavior. A future implementation could make these two-part formats selectable and record which version was offered, while keeping activity choice, use, and response as separate events.

See the [64-gate AI affordance atlas](ai-gate-affordance-atlas.md) for the gate-level proposals and the [environmental affordance layer](environmental-affordance-layer.md) for consent, choice, and record boundaries.
